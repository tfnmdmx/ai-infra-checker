imu-idc-001 — IMU 必需字段是否完整#

所属模态算子：IMU

active error 时产物无法生成 single input_device_compatibility raw rule v1.0.0 fm-imu-operator v0.13.0

检查输入是否具备完整的 IMU 三轴载荷、硬件时间戳和可用的样本时间戳来源。

白话解释#

  • 做了什么检测： 检查输入是否同时带有加速度、角速度、磁场和所需的时间信息。

  • 为什么会告警或不通过： 缺少任何一组三轴数据或找不到必要时间轴，就无法组成完整 IMU 记录，也无法判断样本发生的时刻。

计算契约#

quality.imu.imu_idc_001(
    imu_record: NPZ arrays timestamps=[T], axes=[T,3],
) -> RuleResult

implementation · registry · test 1 · 计算规范

注意

  • emg_imu_sync_timestamps 一旦存在即视为权威样本时间戳；其内容非法时不会回退到 raw。

  • 字段存在但 shape、dtype 不正确属于 imu-dsf-001，不属于本规则。

  • 规则阶段为 raw；总状态只取已执行规则的最高严重度。

  • 质量或数据异常由 RuleResult 明确记录且进程返回 0；只有运行配置错误返回 1。

校验逻辑#

校验含义#

不通过表示： 任一 XYZ、硬件时间戳缺失，或 raw/sync 样本时间戳均不存在时为 error；具体缺项写入 details.missing_fields

具体检查项#

  1. 确认输入同时包含 emg_imu_accel、emg_imu_gyro 和 emg_imu_mag 三个 XYZ 字段。

  2. 确认存在用于周期与缺口计算的硬件时间戳 emg_imu_hw_us。

  3. 确认至少存在 emg_imu_sync_timestamps 或 emg_imu_ts_raw；两者同时存在时优先使用 sync。

  4. 任一必需字段缺失即按字段发布 error，不用零数组或其他时间戳代填。

执行关系#

前置质检算子： 无。

产物影响： 本规则为 error 时，输出契约已经无法满足，因此本次不会登记产物； 原因由结构化 RuleResult 记录。只要这不是运行配置错误，进程仍返回 0。

失败后建议#

  1. 确认输入文件、模态参数、设备类型和 adapter 与采集数据一致。

  2. 配置错误应修正后重跑；不要把配置问题降级为质量告警。

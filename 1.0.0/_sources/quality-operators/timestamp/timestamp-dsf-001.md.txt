<p class="quality-lead">检查各模态时间轴是否存在、数值有限且严格递增。</p>

## 白话解释

- **做了什么检测：** 检查每个输入流是否有时间轴，并确认时间值有限、没有重复或倒退。
- **为什么会告警或不通过：** 缺少时间轴，或时间出现无效值、重复和倒序时，无法安全确定公共区间。

## 校验逻辑
### 校验含义

**不通过表示：** 缺 timestamps、时间戳非有限或非严格递增为 error

### 具体检查项

1. 对每个输入流确认存在 `timestamps` 字段。
2. 时间戳必须全部有限且严格递增，不允许 NaN、无穷大、重复或倒序。
3. 任一条件不满足时按流发布 error，不借用、排序或修复输入时间轴。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 输入满足检查条件 |
| warn | not_applicable |
| error | 缺 timestamps、时间戳非有限或非严格递增为 error |

- 结构校验按离散条件判定，不进行隐式修复或默认跳过。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，输出契约已经无法满足，因此本次不会登记产物；
原因由结构化 RuleResult 记录。只要这不是运行配置错误，进程仍返回 0。

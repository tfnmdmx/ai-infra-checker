<p class="quality-lead">检查 EMG 数据的有符号采样率偏差比例，并按绝对幅度边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 用实际时间间隔算出采样速度，并和应有的每秒 2000 个样本比较。
- **为什么会告警或不通过：** 偏差超过 0.1% 会告警，超过 0.5% 会失败；这通常表示设备时钟、时间单位或采集配置不正确。

## 计算定义
### 指标含义

表示实测采样率相对 2000 Hz 期望采样率的有符号偏差；正值代表采样偏快，负值代表偏慢，判定时使用绝对值。

计算使用 `emg_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = (measured_rate_hz - expected_rate_hz) / expected_rate_hz
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | abs(value)>0.1% 且 <=0.5% |
| error | abs(value)>0.5% |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

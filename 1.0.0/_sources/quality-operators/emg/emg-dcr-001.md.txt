<p class="quality-lead">检查EMG 数据的「有效时长」，并按公开边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 计算这段肌电记录从第一个样本到最后一个样本一共覆盖了多久。
- **为什么会告警或不通过：** 记录覆盖时间短于任务要求，通常说明采集提前结束、开头或结尾数据缺失，因而没有足够长的可用数据。

## 计算定义
### 指标含义

表示输入 EMG 时间轴从首个样本到末个样本覆盖的时长，用于判断记录是否达到任务要求；它不是有肌肉活动的累计时长。

计算使用 `emg_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
value = timestamps[-1] - timestamps[0]
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | not_applicable |
| error | 满足 error 条件；完整边界：小于 min_duration_s 时 error，否则 pass |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`
为准。

## 失败后建议

1. 确认采集覆盖了任务要求的最小时长。
2. 排查提前结束、截断或错误的记录边界。

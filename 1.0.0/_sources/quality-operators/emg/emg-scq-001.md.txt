<p class="quality-lead">统计处理后 EMG 中标准差低于 1.0 uV 的通道数量，并在 details.channels 中记录具体通道编号。</p>

## 白话解释

- **做了什么检测：** 查看 16 路肌电信号各自有没有正常起伏，并数出几乎是一条直线的通道。
- **为什么会告警或不通过：** 只要有通道几乎不变化就不通过，常见原因是电极脱落、接触不良、线缆或采集通道故障。

## 计算定义
### 指标含义

表示处理后 16 个 EMG 通道中，整段标准差低于 1.0 uV 的通道数量；这些近乎恒定的通道通常无法提供有效肌电变化。

计算使用 `emg_record`，
结果类型为 `integer`，
单位为 count。

### 计算方法

```text
value = count(std(emg[:, channel]) < 1.0 uV)
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | not_applicable |
| error | 任一通道的标准差 < 1.0 uV，即死通道数 > 0 |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`

## 失败后建议

1. 按 details.channels 中的通道编号检查传感器、佩戴和采集环境。
2. 保留原始数据与本规则数值用于复核。

<p class="quality-lead">检查EMG 数据的「全局信号标准差」，并按公开边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 把所有通道放在一起看整体起伏是否太小，用来发现整段肌电都很弱的情况。
- **为什么会告警或不通过：** 整体幅度低于门槛会告警，可能是佩戴或接触普遍不佳，也可能整段没有有效动作；本规则不单独判失败。

## 计算定义
### 指标含义

表示处理后全部样本和全部通道合在一起的总体标准差，用于识别整段信号整体幅度过低，而不是定位某一个死通道。

计算使用 `emg_record`，
结果类型为 `number`，
单位为 uV。

### 计算方法

```text
value = std(emg) over all processed samples and channels
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | 满足 warn 条件且未满足 error 条件；完整边界：<8 warn |
| error | not_applicable |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`

## 失败后建议

1. 按 details 中的通道或视频证据检查传感器、佩戴和采集环境。
2. 保留原始数据与本规则数值用于复核。

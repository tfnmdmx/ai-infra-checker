<p class="quality-lead">检查EMG 数据的「工频比例偏高通道数」，并按公开边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 检查每路肌电中来自市电的 50 Hz 嗡声是否太明显，并统计受影响的通道数。
- **为什么会告警或不通过：** 检测到受工频干扰的通道就会告警，常见原因是接地、屏蔽或电极接触不好；本规则只告警，不判失败。

## 计算定义
### 指标含义

对每个通道计算 48–52 Hz 功率占 10–500 Hz 功率的比例，并统计比例超过 0.15 的通道数；数量越多表示工频干扰覆盖越广。

计算使用 `emg_record`，
结果类型为 `integer`，
单位为 count。

### 计算方法

```text
value = count(channels whose powerline ratio exceeds its limit)
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | 满足 warn 条件且未满足 error 条件；完整边界：存在时 warn |
| error | not_applicable |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。

## 失败后建议

1. 按 details 中的通道或视频证据检查传感器、佩戴和采集环境。
2. 保留原始数据与本规则数值用于复核。

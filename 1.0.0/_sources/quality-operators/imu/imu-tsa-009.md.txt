<p class="quality-lead">检查 IMU 数据的有符号采样率偏差比例，并按绝对幅度边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 根据硬件时间算出实际采样速度，并和应有的每秒 100 个样本比较。
- **为什么会告警或不通过：** 偏差超过 1% 会告警，超过 5% 会失败；常见原因是设备时钟、时间单位或采样设置不正确。

## 计算定义
### 指标含义

表示硬件时间戳推得的实测采样率相对 100 Hz 期望值的有符号偏差；正值代表偏快，负值代表偏慢，状态按绝对偏差判断。

计算使用 `imu_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = (measured_rate_hz - expected_rate_hz) / expected_rate_hz
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | abs(value)>1% 且 <=5% |
| error | abs(value)>5% |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

<p class="quality-lead">检查IMU 数据的「最大时间间隔」，并按公开边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 找出相邻两个 IMU 样本之间最长的一次等待时间，用来发现局部停采或断流。
- **为什么会告警或不通过：** 最长间隔超过 50 毫秒会告警，表示中间可能漏掉一段样本；本规则只告警，不单独判失败。

## 计算定义
### 指标含义

表示 IMU 硬件时间戳相邻样本间隔中的最大值，单位为秒；它反映记录中最严重的一次局部停顿或采样缺口。

计算使用 `imu_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
hw_seconds = emg_imu_hw_us / 1e6 if median(abs(diff(emg_imu_hw_us))) > 1 else emg_imu_hw_us
value = max(diff(hw_seconds))
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中 warn 或 error 条件 |
| warn | 满足 warn 条件且未满足 error 条件；完整边界：>50 ms warn |
| error | not_applicable |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。

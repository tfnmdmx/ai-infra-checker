## 白话解释

- **做了什么检测：** 检查关节角通用幅值上限；不能仅凭数值断定角度单位或解剖学合理性。
- **为什么会告警或不通过：** 最大绝对关节角 >2*pi+0.5 rad 时 error，停止运动计算。

## 计算定义
### 指标含义

检查关节角通用幅值上限；不能仅凭数值断定角度单位或解剖学合理性。

计算使用 `pose_record`，
结果类型为 `number`，
单位为 rad。

### 计算方法

```text
value = max(abs(joint_angles))
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中异常条件。 |
| warn | not_applicable |
| error | 最大绝对关节角 >2*pi+0.5 rad 时 error，停止运动计算。 |

- 等号归属按上述比较符；不通过放宽阈值修复数据。

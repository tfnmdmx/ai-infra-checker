<p class="quality-lead">统计有效相邻评估点中最大关节角变化小于 0.001 rad 的间隔比例；达到 100% 时 error。</p>

## 白话解释

- **做了什么检测：** 检查所有有效相邻评估点是否均被判为静止，同时记录最长连续静止时长。
- **为什么会告警或不通过：** 静止间隔比例达到 100% 时失败，低于 100% 时通过；沿用每个间隔角度变化小于 0.001 rad 的定义。

## 计算定义
### 指标含义

统计有效相邻评估点中最大关节角变化小于 0.001 rad 的间隔比例；达到 100% 时 error。评估网格沿用 stride=max(1,round(native_fs/100))；速度与静止时长使用真实时间戳。

计算使用 `pose_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = count(max_joint(abs(q[i+1]-q[i])) < 0.001 rad) / valid_evaluated_intervals
```

- **聚合口径：** 单条记录发布一个静止比例；最长连续静止时长和有效间隔数量保留在 details。
- **无法计算时：** 结构、数值、时间戳或角度范围前置未通过，或没有有效评估间隔时，不执行；原因记录于 summary.skipped_rules。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 静止间隔比例 <1.0。 |
| warn | not_applicable |
| error | 静止间隔比例达到 1.0（100%）。 |

- 比例恰好 100% 时 error；99.9% 时 pass，不做百分数四舍五入后判定。
- 单个间隔最大关节角变化恰好 0.001 rad 时不计为静止。

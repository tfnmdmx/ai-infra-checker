## 计算定义
### 指标含义

按真实时间差计算有效相邻采样点之间的角速度，统计超过 50 rad/s 的间隔比例。

计算使用 `pose_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = count(max_joint(abs(diff(q) / actual_dt)) > 50 rad/s) / evaluated_valid_intervals
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中异常条件。 |
| warn | 高角速度间隔比例 >1% 告警，>=5% 失败。 |
| error | 高角速度间隔比例 >1% 告警，>=5% 失败。 |

- 等号归属按上述比较符；不通过放宽阈值修复数据。

- **做了什么检测：** 按期望周期估算过滤前最大连续缺失时长；局部停顿独立判级。

## 计算定义
### 指标含义

按期望周期估算过滤前最大连续缺失时长；局部停顿独立判级。

计算使用 `pose_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
value = max(max(rint(diff(raw_finite_timestamps) / expected_dt), 1) - 1) * expected_dt
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 未命中异常条件。 |
| warn | 缺口 >=2×expected_dt 告警，>=4×expected_dt 失败；不依赖累计净缺失率。 |
| error | 缺口 >=2×expected_dt 告警，>=4×expected_dt 失败；不依赖累计净缺失率。 |

- 等号归属按上述比较符；不通过放宽阈值修复数据。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`
为准。

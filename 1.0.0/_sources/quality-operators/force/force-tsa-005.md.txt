<p class="quality-lead">检查FORCE 数据的「最大连续缺口」，并按公开边界发布独立 RuleResult。</p>

## 白话解释

- **做了什么检测：** 找出相邻两个力样本之间最长的一次等待，用来发现最严重的局部停采或断流。
- **为什么会告警或不通过：** 连续缺失达到 2 个正常周期会告警，达到 4 个周期会失败；判级只看最严重的一次局部缺口。

## 计算定义
### 指标含义

根据相邻时间戳间隔估算每处连续缺失的样本周期数，value 为最严重缺口的缺失周期数乘 expected_dt；它不等于包含正常一个周期在内的原始最大相邻间隔。

计算使用 `force_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
skipped_per_gap = max(round(diff(force_timestamps) / expected_dt) - 1, 0)
value = max(skipped_per_gap) * expected_dt
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | value < 2×expected_dt |
| warn | 2×expected_dt <= value < 4×expected_dt |
| error | value >= 4×expected_dt |

- 严格遵循本页判定中的 >、>=、<、<=；等号归属以明确写出的比较符为准。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`
为准。

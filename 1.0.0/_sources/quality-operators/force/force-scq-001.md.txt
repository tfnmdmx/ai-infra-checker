<p class="quality-lead">检查 Force 通道在整段记录中是否近乎恒定，并发布逐通道 RuleResult。</p>

## 白话解释

- **做了什么检测：** 查看每个力传感器通道在整段记录中是否还有可辨认的变化。
- **为什么会告警或不通过：** 通道几乎完全是一条直线时会告警，可能是无信号、卡死，也可能是稳定的零值或高载荷。

## 计算定义
### 指标含义

对每个传感器/手指通道计算整段记录的总体标准差；低于 1e-9 N 只说明通道近乎恒定，不能单凭该事实区分无信号、零值和稳定高载荷。

计算使用 `force_record`，
结果类型为 `number`，
单位为 N。

### 计算方法

```text
value = std(full_record_force) for each sensor and finger
```



### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 通道整段标准差 >= 1e-9 N |
| warn | 通道整段标准差 < 1e-9 N |
| error | not_applicable |

- 标准差恰好等于 1e-9 N 时为 pass。

## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`
为准。

## 失败后建议

1. 按 details 中的通道或视频证据检查传感器、佩戴和采集环境。
2. 保留原始数据与本规则数值用于复核。

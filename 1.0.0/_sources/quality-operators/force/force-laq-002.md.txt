<p class="quality-lead">按传感器和通道联合检查完整首 5 秒的平均受力、高位受力（p95）和波动（标准差），保留三项独立证据。</p>

## 白话解释

- **做了什么检测：** 检查开始 5 秒是否充分放松：平均载荷是否偏高、大多数较高的力值是否偏高、力值波动是否偏大。
- **为什么会告警或不通过：** 均值、p95 或标准差任一超过设备对应告警门槛时 warn；只有绝对均值超过失败门槛才 error。

## 计算定义
### 指标含义

每个通道完整首 5 秒计算带符号均值的绝对值、绝对力值第 95 百分位及总体标准差；联合状态取三项中的最高严重度。实例 value 保留绝对均值，p95/std 数值与三项状态保存在实例 details 中。

计算使用 `force`、`timestamps`，
结果类型为 `number`（允许 `null`），
单位为 N。

### 计算方法

```text
rest = timestamps < timestamps[0] + 5.0
mean_n = mean(force[rest])
value = abs(mean_n)
p95_n = percentile(abs(force[rest]), 95)
std_n = std(force[rest], ddof=0)
error = value > mean_error
warn = not error and (value > mean_warn or p95_n > p95_warn or std_n > std_warn)
```

- **聚合口径：** 每个 sensor_finger 独立计算实例，规则状态取全部实例中的最高严重度。
- **无法计算时：** 缺少有效时间轴、存在非有限值或记录不足以完整覆盖首 5 秒时不执行静息统计。


### 判定边界

| 状态 | 条件 |
| --- | --- |
| pass | 三项均不超过各自 warn 阈值：CMCU05/CMCU05B value <=0.05、p95 <=0.15、std <=0.03 N；Gen3 value <=0.10、p95 <=0.30、std <=0.05 N。 |
| warn | 绝对均值不超过 error 阈值，且均值、p95 或 std 任一超过对应 warn 阈值。 |
| error | 只有绝对均值超过 error 阈值：CMCU05/CMCU05B value >0.20 N；Gen3 value >0.50 N。p95/std 不单独升级到 error。 |

- 所有升级比较均为严格大于。
- 三项均等于各自 warn 阈值时 pass；均值等于 error 阈值时 warn。
- 均值 error 不抑制 p95/std 的分项状态和超限诊断。

## 失败后建议

1. 确认首五秒是否按采集规范保持静息且没有持续按压。
2. 检查佩戴预载、传感器基线和 Force 单位转换。

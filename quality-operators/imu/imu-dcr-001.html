imu-dcr-001 — 有效时长#

所属模态算子：IMU

active error 时产物可生成 single duration_coverage processed rule v3.0.0 fm-imu-operator v0.14.0

计算 IMU 最终时间轴首末样本之间的时间跨度，并与任务最小时长比较。

先看懂这条规则#

  • 检查什么： 计算这段惯性传感器记录从第一个样本到最后一个样本实际覆盖了多久。

  • value 是什么： 表示最终 IMU 时间轴首末样本之间的覆盖时长，用于判断三轴惯性数据是否达到任务要求；它不按样本数和名义频率估算。

  • 为什么不是 pass： 覆盖时间短于任务要求，通常说明采集提前停止或首尾数据缺失，因此可用的运动记录不够长。

判定标准#

状态

完整条件

通过 pass

value >= min_duration_s；记录时长达到任务要求。

告警 warn

不会出现；本规则不使用 warn 状态。

失败 error

value < min_duration_s；记录时长没有达到任务要求。

边界怎么算：

  • value 恰好等于 min_duration_s 时为 pass。

计算定义#

计算使用 imu_record， 结果类型为 number， 单位为 s。

计算方法#

value = timestamps[-1] - timestamps[0]

执行关系#

前置质检算子： 无。

产物影响： 本规则为 error 时，只记录质量异常，不阻止生成结构上有效的产物。 如果后续处理或写入本身失败，仍可能没有产物；最终事实以 processed_ok 与 artifacts 为准。

失败后建议#

  1. 确认采集覆盖了任务要求的最小时长。

  2. 排查提前结束、截断或错误的记录边界。

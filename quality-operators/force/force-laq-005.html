force-laq-005 — 全程五指受力模式#

所属模态算子：Force

active error 时产物可生成 multi · finger_group label_action_quality raw rule v1.0.0 fm-force-label-operator v3.6.0

检查每个传感器/手的五指在整段有效记录中是否命中不通过条件。

先看懂这条规则#

  • 检查什么： 使用全程绝对 Fz 检查五指最大受力和单指最低受力。

  • 什么情况下不通过： 五指全程最大力不超过 1 N，或至少一指全程不低于 0.5 N 时为 error。

判定标准#

状态

怎么判

pass

max_all_fingers_n > 1.0 N 且 max_of_finger_minima_n < 0.5 N。

warn

本规则不使用 warn。

error

max_all_fingers_n <= 1.0 N，或 max_of_finger_minima_n >= 0.5 N。

边界怎么算：

  • 1.0 N 是包含上界，恰好等于 1.0 N 时触发第一不通过分支。

  • 0.5 N 是包含下界，恰好等于 0.5 N 时触发第二不通过分支。

注意

  • Fz 以绝对值（N）参与比较，避免坐标方向导致阈值语义反转。

  • 每个传感器/手独立判断；左右手不会合并成一个五指组。

计算定义#

计算使用 force、timestamps， 结果类型为 boolean， 单位为 N/A。

计算方法#

max_all = max_i(max_t(abs(force[t,i]))); max_min = max_i(min_t(abs(force[t,i]))); error = (max_all <= 1.0) or (max_min >= 0.5)

  • 聚合口径： 每个传感器/手的五指组独立发布一个实例，整体状态取实例中的最高严重度。

  • 无法计算时： 缺少五指、存在非有限值或对应时间轴无效时不执行，并记录 skipped_rules。

执行关系#

前置质检算子：

  • force-dsf-003

  • force-nva-002

  • force-tsa-003

不执行条件：

  • 任一五指组不完整或其 Force 时间轴缺失、无效。

产物影响： 本规则为 error 时，只记录质量异常，不阻止生成结构上有效的产物。 如果后续处理或写入本身失败，仍可能没有产物；最终事实以 processed_ok 与 artifacts 为准。

失败后建议#

  1. 检查五指传感器是否完整、时间轴是否连续且与标签等长。

  2. 结合 details.finger_extrema 判断是最大力过高还是所有手指都曾降到 0.5 N 以下。

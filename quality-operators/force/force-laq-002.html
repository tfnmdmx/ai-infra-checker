force-laq-002 — 前 3 秒静息受力异常#

所属模态算子：Force

active error 时产物可生成 multi · sensor_finger label_action_quality raw rule v6.0.0 fm-force-label-operator v3.2.0

按传感器和通道联合检查完整前 3 秒的平均受力、高位受力（p95）和波动（标准差），保留三项独立证据。

先看懂这条规则#

  • 检查什么： 检查开始 3 秒是否充分放松：平均载荷是否偏高、大多数较高的力值是否偏高、力值波动是否偏大。

  • value 是什么： 每个通道的 value 是前 3 秒平均力的绝对值。details.p95_n 表示 95% 的绝对力值不超过多少，details.std_n 表示这 3 秒内力值波动多大；三项中最严重的状态作为该通道状态。

  • 为什么不是 pass： 均值、p95 或标准差任一超过设备对应告警门槛时 warn；只有绝对均值超过失败门槛才 error。

判定标准#

状态

完整条件

通过 pass

CMCU05/CMCU05B 同时满足 value <=0.05、p95 <=0.15、std <=0.03 N；Gen3 同时满足 value <=0.10、p95 <=0.30、std <=0.05 N。

告警 warn

CMCU05/CMCU05B 满足 value <=0.20 N，且 value >0.05、p95 >0.15 或 std >0.03 N 至少一项成立；Gen3 满足 value <=0.50 N，且 value >0.10、p95 >0.30 或 std >0.05 N 至少一项成立。

失败 error

只有绝对均值超过 error 阈值：CMCU05/CMCU05B value >0.20 N；Gen3 value >0.50 N。p95/std 不单独升级到 error。

边界怎么算：

  • 所有升级比较均为严格大于。

  • 三项均等于各自 warn 阈值时 pass；均值等于 error 阈值时 warn。

  • 均值 error 不抑制 p95/std 的分项状态和超限诊断。

注意

  • 稳定高载荷不能在缺少独立空载标定时自动归因为零漂。

  • force-scq-001 告警不会阻断本规则，恒定高载荷仍按均值阈值判定。

  • 保留 force-laq-002，移除独立 force-laq-003/004；历史结果不改写，按 rule_version 区分旧版纯均值判定与新版联合判定。

  • 阈值为 warn_any（mean_abs_gt_n、p95_gt_n、std_gt_n）和 error_gt（绝对均值）；值与阈值均以 N 为单位。

  • 消费者从 details.instances[].details 获取 p95_n、std_n 及 mean_status/p95_status/std_status（pass/warn/error）。主值为均值时，p95/std 超限也可能使实例 warn。

计算定义#

计算使用 force、timestamps， 结果类型为 number（允许 null）， 单位为 N。

计算方法#

rest = timestamps < timestamps[0] + 3.0
mean_n = mean(force[rest])
value = abs(mean_n)
p95_n = percentile(abs(force[rest]), 95)
std_n = std(force[rest], ddof=0)
error = value > mean_error
warn = not error and (value > mean_warn or p95_n > p95_warn or std_n > std_warn)

  • 聚合口径： 每个 sensor_finger 独立计算实例，规则状态取全部实例中的最高严重度。

  • 无法计算时： 缺少有效时间轴、存在非有限值或记录不足以完整覆盖前 3 秒时不执行静息统计。

不执行条件：

  • Force 时间轴从首样本起覆盖不足 3 秒，并在 summary.skipped_rules 记录原因。

产物影响： 本规则为 error 时，只记录质量异常，不阻止生成结构上有效的产物。 如果后续处理或写入本身失败，仍可能没有产物；最终事实以 processed_ok 与 artifacts 为准。

失败后建议#

  1. 确认前 3 秒是否按采集规范保持静息且没有持续按压。

  2. 检查佩戴预载、传感器基线和 Force 单位转换。

pose-laq-002 — 原始无效帧比例#

所属模态算子：Pose

active error 时产物可生成 single label_action_quality raw rule v1.2.0 fm-pose-label-operator v0.16.0

计算转换前被丢弃的原始 Pose 帧占全部原始帧的比例。

先看懂这条规则#

  • 检查什么： 把明确标为无效、时间是 NaN/Inf，或姿态值含 NaN/Inf 的原始帧都算作坏帧，再除以原始总帧数。

  • 什么情况下不通过： 坏帧达到 20% 说明有效姿态已经明显缺失；超过 40% 时可用数据不足，因此升级为失败。

判定标准#

状态

怎么判

pass

0 <= value < 0.20。

warn

0.20 <= value <= 0.40。

error

value > 0.40。

边界怎么算：

  • value 恰好为 20% 或 40% 时都是 warn；只有严格超过 40% 才是 error。

计算定义#

计算使用 pose_record， 结果类型为 number， 单位为 ratio。

计算方法#

value = count(~frame_valid) / raw_samples

  • 聚合口径： 单条记录发布一个标量。

  • 无法计算时： 前置失败不执行，并记录 skipped_rules。

执行关系#

前置质检算子： 无。

产物影响： 本规则为 error 时，只记录质量异常，不阻止生成结构上有效的产物。 如果后续处理或写入本身失败，仍可能没有产物；最终事实以 processed_ok 与 artifacts 为准。

失败后建议#

  1. 查看 details 中的 invalid_flag_samples、nonfinite_timestamp_samples 和 nonfinite_value_samples，先确定坏帧来自哪个环节。

  2. 检查上游跟踪状态、时间戳生成和姿态序列化，不要用填零掩盖无效帧。

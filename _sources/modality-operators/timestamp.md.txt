# Timestamp 模态算子

<p class="quality-lead">单流复验后原样发布；多流检查输入契约并裁剪公共时间窗口。</p>

<div class="quality-meta">
  <code class="meta-kind">fm-timestamp-operator</code>
  <code class="meta-version">v0.15.0</code>
  <code class="meta-stage">multimodal</code>
  <code class="meta-domain">6 quality operators</code>
</div>

```{admonition} 跨模态特例
:class: important

Timestamp 位于模态算子层，接收一个或多个已处理模态流。单流只复验并原样发布；多流执行
公共时间段判定和原生行裁剪。它不代表一个独立传感器模态。
```

| 属性 | 值 |
| --- | --- |
| 包名 | `fm-timestamp-operator` |
| 包版本 | `0.15.0` |
| 输入边界 | 一个或多个已处理模态 NPZ |
| 默认产物 | `每个输入流一个 <work-dir>/<name>/processed.npz` |
| 质检算子数 | 6 |

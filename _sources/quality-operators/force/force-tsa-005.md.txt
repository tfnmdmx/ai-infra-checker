<p class="quality-lead">按期望采样周期估算 Force 一次最长连续丢样的时长。</p>

## 先看懂这条规则

- **检查什么：** 找出相邻两个力样本之间最长的一次等待，用来发现最严重的局部停采或断流。
- **`value` 是什么：** 根据相邻时间戳间隔估算每处连续缺失的样本周期数，value 为最严重缺口的缺失周期数乘 expected_dt；它不等于包含正常一个周期在内的原始最大相邻间隔。
- **为什么不是 pass：** 连续缺失达到 2 个正常周期会告警；达到 4 个周期且整段累计缺失比例超过 1% 才会失败。

### 判定标准

| 状态 | 完整条件 |
| --- | --- |
| **通过 `pass`** | value < 2×expected_dt |
| **告警 `warn`** | 2×expected_dt <= value < 4×expected_dt；或 value >= 4×expected_dt 且 missing_ratio <= 1% |
| **失败 `error`** | value >= 4×expected_dt 且 missing_ratio > 1% |

**边界怎么算：**

- value 恰好为 2 个周期时是 warn；恰好为 4 个周期且 missing_ratio > 1% 时是 error。
- missing_ratio 恰好为 1% 时不是 error。

## 配置参数

本质检算子没有独立配置参数。

## 计算定义
计算使用 `force_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
skipped_per_gap = max(round(diff(force_timestamps) / expected_dt) - 1, 0)
value = max(skipped_per_gap) * expected_dt
```



## 执行关系

**前置质检算子：** 无。

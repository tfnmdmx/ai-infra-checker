<p class="quality-lead">按传感器和通道联合检查完整前 3 秒的平均受力、高位受力（p95）和波动（标准差），保留三项独立证据。</p>

## 先看懂这条规则

- **检查什么：** 检查开始 3 秒是否充分放松：平均载荷是否偏高、大多数较高的力值是否偏高、力值波动是否偏大。
- **`value` 是什么：** 每个通道的 value 是前 3 秒平均力的绝对值。details.p95_n 表示 95% 的绝对力值不超过多少，details.std_n 表示这 3 秒内力值波动多大；三项中最严重的状态作为该通道状态。
- **为什么不是 pass：** 均值、p95 或标准差任一超过设备对应告警门槛时 warn；只有绝对均值超过失败门槛才 error。

### 判定标准

| 状态 | 完整条件 |
| --- | --- |
| **通过 `pass`** | CMCU05/CMCU05B 同时满足 value <=0.05、p95 <=0.15、std <=0.03 N；Gen3 同时满足 value <=0.10、p95 <=0.30、std <=0.05 N。 |
| **告警 `warn`** | CMCU05/CMCU05B 满足 value <=0.20 N，且 value >0.05、p95 >0.15 或 std >0.03 N 至少一项成立；Gen3 满足 value <=0.50 N，且 value >0.10、p95 >0.30 或 std >0.05 N 至少一项成立。 |
| **失败 `error`** | 只有绝对均值超过 error 阈值：CMCU05/CMCU05B value >0.20 N；Gen3 value >0.50 N。p95/std 不单独升级到 error。 |

**边界怎么算：**

- 所有升级比较均为严格大于。
- 三项均等于各自 warn 阈值时 pass；均值等于 error 阈值时 warn。
- 均值 error 不抑制 p95/std 的分项状态和超限诊断。

| `timestamps` | raw | `float64` | `[T]` | s | 是 | 与目标 Force 通道等长的时间轴。 |

## 配置参数

| 名称 | 类型 | 默认值/必需 | 来源 | 说明 |
| --- | --- | --- | --- | --- |
| `rest_window_s` | `float` | `3.0` | implementation_constant | 从首样本开始使用的静息区间。 |
| `sensor_thresholds` | `mapping` | 必填 | sensor_profile | CMCU05/CMCU05B：均值 warn/error 为 0.05/0.20 N，p95 warn 为 0.15 N，std warn 为 0.03 N；Gen3 分别为 0.10/0.50、0.30、0.05 N。 |

## 计算定义
计算使用 `force`、`timestamps`，
结果类型为 `number`（允许 `null`），
单位为 N。

### 计算方法

```text
rest = timestamps < timestamps[0] + 3.0
mean_n = mean(force[rest])
value = abs(mean_n)
p95_n = percentile(abs(force[rest]), 95)
std_n = std(force[rest], ddof=0)
error = value > mean_error
warn = not error and (value > mean_warn or p95_n > p95_warn or std_n > std_warn)
```

- **聚合口径：** 每个 sensor_finger 独立计算实例，规则状态取全部实例中的最高严重度。
- **无法计算时：** 缺少有效时间轴、存在非有限值或记录不足以完整覆盖前 3 秒时不执行静息统计。

## 失败后建议

1. 确认前 3 秒是否按采集规范保持静息且没有持续按压。
2. 检查佩戴预载、传感器基线和 Force 单位转换。

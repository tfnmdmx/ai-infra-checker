<p class="quality-lead">找出处理后 20 路关节角中的最大绝对值，排查单位或转换明显错误。</p>

## 先看懂这条规则

- **检查什么：** 在整段数据的所有关节里找绝对值最大的角度，检查它是否大到超出通用保护上限。
- **什么情况下不通过：** 最大值超过约 6.783 rad 时失败，通常要检查度和弧度是否混用、关节映射是否错位，或转换结果是否损坏。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value <= 2*pi+0.5 rad（约 6.783185 rad）。 |
| **`warn`** | 不会出现；本规则不使用 warn 状态。 |
| **`error`** | value > 2*pi+0.5 rad（约 6.783185 rad）；后续静止和角速度规则不执行。 |

**边界怎么算：**

- value 恰好等于 2*pi+0.5 rad 时为 pass。

## 计算定义
计算使用 `pose_record`，
结果类型为 `number`，
单位为 rad。

### 计算方法

```text
value = max(abs(joint_angles))
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。

## 失败后建议

1. 确认输入和转换结果使用弧度，而不是把角度值直接当弧度。
2. 检查关节顺序、手侧、adapter 与转换模型是否匹配。

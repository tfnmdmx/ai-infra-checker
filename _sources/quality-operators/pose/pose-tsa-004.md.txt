<p class="quality-lead">根据原始 Pose 时间戳估算一次最长的连续丢样时长。</p>

## 先看懂这条规则

- **检查什么：** 把相邻原始时间戳的间隔换算成“中间大约少了几个正常采样周期”，取最严重的一次，并换算成秒。
- **什么情况下不通过：** 一次连续少 2 个周期就告警，少 4 个周期就失败；这里只看最严重的局部断流，不看整段累计少了多少帧。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value < 2*expected_dt。 |
| **`warn`** | 2*expected_dt <= value < 4*expected_dt。 |
| **`error`** | value >= 4*expected_dt。 |

**边界怎么算：**

- value 恰好为 2 个周期时是 warn；恰好为 4 个周期时是 error。

## 配置参数

本质检算子没有独立配置参数。

## 计算定义
计算使用 `pose_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
value = max(max(rint(diff(raw_finite_timestamps) / expected_dt), 1) - 1) * expected_dt
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。


## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`
为准。

<p class="quality-lead">统计有效相邻评估点中最大关节角变化小于 0.001 rad 的间隔比例；达到 100% 时 error。</p>

## 先看懂这条规则

- **检查什么：** 最多按每秒 100 个点抽查相邻姿态；如果两点之间所有关节的变化都小于 0.001 rad，就把这段间隔算作静止。
- **什么情况下不通过：** 所有可评估间隔都静止时失败，说明整段没有检测到一次超过门槛的动作；只要有一个间隔不是静止就通过。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | 0 <= value < 1.0；至少一个有效评估间隔的最大关节变化 >= 0.001 rad。 |
| **`warn`** | 不会出现；本规则不使用 warn 状态。 |
| **`error`** | value == 1.0；全部有效评估间隔都满足最大关节变化 < 0.001 rad。 |

**边界怎么算：**

- 比例恰好 100% 时 error；99.9% 时 pass，不做百分数四舍五入后判定。
- 单个间隔最大关节角变化恰好 0.001 rad 时不计为静止。

## 配置参数

本质检算子没有独立配置参数。

## 计算定义
计算使用 `pose_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = count(max_joint(abs(q[i+1]-q[i])) < 0.001 rad) / valid_evaluated_intervals
```

- **聚合口径：** 单条记录发布一个静止比例；最长连续静止时长和有效间隔数量保留在 details。
- **无法计算时：** 结构、数值、时间戳或角度范围前置未通过，或没有有效评估间隔时，不执行；原因记录于 summary.skipped_rules。

## 失败后建议

1. 回看采集过程，确认受试者确实完成了动作，而不是全程保持不动。
2. 若画面中有动作但关节角仍不变，检查跟踪器是否冻结、手侧和 adapter 是否匹配。

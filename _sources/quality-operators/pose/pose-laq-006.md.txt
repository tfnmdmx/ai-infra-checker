<p class="quality-lead">统计最大关节角速度超过 50 rad/s 的相邻评估间隔占比。</p>

## 先看懂这条规则

- **检查什么：** 最多按每秒 100 个点抽查相邻姿态，用真实时间差计算每个关节转动有多快，再统计其中“任一关节超过 50 rad/s”的间隔比例。
- **`value` 是什么：** value = 高角速度间隔数 / 有效评估间隔数。一个间隔中只要任一关节的绝对角速度 > 50 rad/s，就计入分子。
- **为什么不是 pass：** 这类突跳超过全部有效间隔的 1% 就告警，达到 5% 就失败，通常要排查时间戳过近、跟踪跳点或姿态转换异常。

### 判定标准

| 状态 | 完整条件 |
| --- | --- |
| **通过 `pass`** | 0 <= value <= 0.01。 |
| **告警 `warn`** | 0.01 < value < 0.05。 |
| **失败 `error`** | value >= 0.05。 |

**边界怎么算：**

- value 恰好为 1% 时为 pass；恰好为 5% 时为 error。

## 计算定义
计算使用 `pose_record`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
value = count(max_joint(abs(diff(q) / actual_dt)) > 50 rad/s) / evaluated_valid_intervals
```

- **聚合口径：** 单条记录发布一个标量。
- **无法计算时：** 前置失败不执行，并记录 skipped_rules。

## 失败后建议

1. 对照 details.max_angular_velocity_rad_s 定位突跳幅度，检查原始跟踪是否跳点。
2. 核对时间戳单位和相邻间隔；过小的时间差会把正常角度变化放大成异常角速度。

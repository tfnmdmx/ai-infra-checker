<p class="quality-lead">找出相邻 IMU 质检时间戳之间的最大间隔，识别局部停采。</p>

## 先看懂这条规则

- **检查什么：** 找出相邻两个 IMU 样本之间最长的一次等待时间，用来发现局部停采或断流。
- **什么情况下不通过：** 最长间隔超过 50 毫秒会告警，表示中间可能漏掉一段样本；本规则只告警，不单独判失败。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value <= 0.05 s（50 ms）。 |
| **`warn`** | value > 0.05 s（50 ms）。 |
| **`error`** | 不会出现；本规则不使用 error 状态。 |

**边界怎么算：**

- 最大间隔恰好为 50 ms 时为 pass。

## 计算定义
计算使用 `imu_record`，
结果类型为 `number`，
单位为 s。

### 计算方法

```text
hw_seconds = emg_imu_hw_us / 1e6 if median(abs(diff(emg_imu_hw_us))) > 1 else emg_imu_hw_us
value = max(diff(hw_seconds))
```

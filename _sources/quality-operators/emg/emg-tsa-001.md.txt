# `emg-tsa-001` — EMG 时间戳是否严格递增

<p class="quality-lead">检查 EMG 时间戳能否与信号样本一一对应，且每个值有效、时间顺序严格递增。</p>

## 先看懂这条规则

- **检查什么：** 核对每个肌电样本都有一个时间点，而且时间一直向前走，没有空值、重复或倒退。
- **什么情况下不通过：** 样本与时间对不上、时间无效、重复或倒退时会失败，因为程序无法可靠还原信号的先后顺序和持续时间。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | 时间戳与 EMG 样本等长，且有限、严格递增并形成正时长 |
| **`warn`** | 不会出现；本规则不使用 warn 状态。 |
| **`error`** | 时间戳过少、与样本不等长、含 NaN/Inf、重复、倒退或首尾时长不大于 0 时为 error |

**边界怎么算：**

- 结构校验按离散条件判定，不进行隐式修复或默认跳过。

### 具体检查项

1. 检查时间戳数量是否与 EMG 样本数相同，并且至少包含 2 个时间点。
2. 检查所有时间戳是否为有限数值，即不含 NaN 或正负无穷大。
3. 检查每个时间戳是否都严格大于前一个时间戳，不允许重复或倒退。
4. 检查首尾时间戳形成的时长是否大于 0；通过时输出样本数、起止时间和实际采样率。
5. 本规则不判断字段是否存在；缺少信号或必需时间戳字段由 `emg-idc-001` 判断。

## 失败后建议

1. 检查时间戳数组的长度、单位和顺序，并确认它与 EMG 信号逐样本对应。
2. 结合 details 中的字段或目标实例定位异常流。

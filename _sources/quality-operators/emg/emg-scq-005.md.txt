<p class="quality-lead">比较 40–500 Hz 主信号频带与 500–850 Hz 高频频带的平均功率。</p>

## 先看懂这条规则

- **检查什么：** 比较肌电主要频段和更高频噪声频段的能量，判断真正的肌电是否被高频噪声盖住。
- **什么情况下不通过：** 两者差距太小时会告警，差距很小时会失败；这表示高频噪声相对过强，信号的可信度不足。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value >= 20 dB。 |
| **`warn`** | 10 dB <= value < 20 dB。 |
| **`error`** | value < 10 dB。 |

**边界怎么算：**

- value 恰好为 10 dB 时是 warn；恰好为 20 dB 时是 pass。

## 数据输入

| 名称 | 来源 | dtype | shape | 单位 | 必需 | 说明 |

| `emg_record` | processed | `NPZ arrays` | `timestamps=[T], emg=[T,16]` | N/A | 是 | EMG 原始记录及处理后信号。 |

## 配置参数

| 名称 | 类型 | 默认值/必需 | 来源 | 说明 |
| --- | --- | --- | --- | --- |
| `error_lt` | `float` | `10.0` | rule_threshold | value 严格小于 10 dB 时为 error。 |
| `warn_lt` | `float` | `20.0` | rule_threshold | value 小于 20 dB 且未进入 error 时为 warn。 |

## 计算定义
计算使用 `emg_record`，
结果类型为 `number`，
单位为 dB。

### 计算方法

```text
value = 10 * log10(P[40,500]Hz / P[500,850]Hz)
```



## 执行关系

**前置质检算子：** 无。


**产物影响：** 本规则为 `error` 时，只记录质量异常，不阻止生成结构上有效的产物。
如果后续处理或写入本身失败，仍可能没有产物；最终事实以 `processed_ok` 与 `artifacts`

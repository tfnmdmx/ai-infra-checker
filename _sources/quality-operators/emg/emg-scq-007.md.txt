<p class="quality-lead">计算陷波后 50 Hz 功率相对 40–200 Hz 平均功率高出的 dB 数。</p>

## 先看懂这条规则

- **检查什么：** 检查去除市电干扰后，信号里是否还残留突出的 50 Hz 嗡声。
- **什么情况下不通过：** 仍有明显残留时会告警，残留很强时会失败，通常说明工频干扰严重或滤波没有充分抑制它。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value <= 0 dB。 |
| **`warn`** | 0 dB < value <= 5 dB。 |
| **`error`** | value > 5 dB。 |

**边界怎么算：**

- value 恰好为 0 dB 时是 pass；恰好为 5 dB 时是 warn。

## 计算定义
计算使用 `emg_record`，
结果类型为 `number`，
单位为 dB。

### 计算方法

```text
value = residual 50 Hz power expressed in dB
```

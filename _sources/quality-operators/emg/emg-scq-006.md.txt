<p class="quality-lead">计算全部 EMG 样本和通道合在一起的总体标准差，识别整段弱信号。</p>

## 先看懂这条规则

- **检查什么：** 把所有通道放在一起看整体起伏是否太小，用来发现整段肌电都很弱的情况。
- **什么情况下不通过：** 整体幅度低于门槛会告警，可能是佩戴或接触普遍不佳，也可能整段没有有效动作；本规则不单独判失败。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value >= 8 uV。 |
| **`warn`** | value < 8 uV。 |
| **`error`** | 不会出现；本规则不使用 error 状态。 |

**边界怎么算：**

- value 恰好等于 8 uV 时为 pass。

## 计算定义
计算使用 `emg_record`，
结果类型为 `number`，
单位为 uV。

### 计算方法

```text
value = std(emg) over all processed samples and channels
```

<p class="quality-lead">统一检查 EMG 处理后持续高幅的最大样本比例与异常通道数，按两者最高严重度发布一条规则。</p>

## 先看懂这条规则

- **检查什么：** 逐通道标记绝对幅值超过 50000 且连续至少 20 帧的样本，记录最严重通道的占比和受影响的通道数。
- **什么情况下不通过：** 出现异常片段就告警；最大比例超过 1% 或异常通道超过 3 个时失败，两个条件任一满足即可。

### 判定标准

| 状态 | 怎么判 |
| --- | --- |
| **`pass`** | value == 0 且 channel_count == 0 |
| **`warn`** | 存在异常片段，且 value <=0.01、channel_count <=3 |
| **`error`** | value >0.01 或 channel_count >3 |

**边界怎么算：**

- 幅值恰好 50000 不命中；连续 19 帧不计入，连续 20 帧开始计入。
- 比例恰好 1% 且通道数不超过 3 时为 warn。
- 通道数恰好 3 且比例不超过 1% 时为 warn；4 个低比例异常通道仍为 error。
- threshold.error_any 的两个条件为 OR 关系；即使 value <=1%，通道数条件也可能使状态为 error。

## 配置参数

| 名称 | 类型 | 默认值/必需 | 来源 | 说明 |
| --- | --- | --- | --- | --- |
| `amplitude_threshold` | `float` | `50000.0` | implementation_constant | 绝对幅值严格大于此值才标记；原始信号使用输入幅值单位，处理后信号单位为 uV。 |
| `min_run_frames` | `int` | `20` | implementation_constant | 连续至少 20 帧才计入异常比例与通道数。 |
| `ratio_gt` | `float` | `0.01` | rule_threshold | 最大异常比例严格大于 1% 即 error。 |
| `channel_count_gt` | `int` | `3` | rule_threshold | 异常通道数严格大于 3 即 error，与比例门限为 OR 关系。 |

## 计算定义
计算使用 `emg`，
结果类型为 `number`，
单位为 ratio。

### 计算方法

```text
hit[c,t] = abs(emg[t,c]) > 50000
ratio[c] = marked_runs_at_least_20_frames(hit[c]) / T
value = max(ratio[c])
channel_count = count(ratio[c] > 0)
```

- **聚合口径：** 一个 RuleResult；value 为最大比例，details.channel_count 为异常通道数，状态取比例与通道数判定的最高严重度。
- **无法计算时：** 输入不满足结构或数值前置条件时不执行；preprocess=False 只跳过滤波，仍执行本规则。

## 失败后建议

1. 对照 details.channels 和 channel_ratios 定位异常通道，检查增益、电极接触与采集干扰。
2. 结合 ratio_status 与 channel_count_status 区分单通道持续异常和多通道少量异常。

<p class="quality-lead">检查各模态数据字段结构及其样本数是否与时间轴匹配。</p>

## 先看懂这条规则

- **检查什么：** 检查每个数据字段都有样本维、不是任意对象，并且样本数与自己的时间戳完全一致。
- **为什么不是 pass：** 结构不明或样本数与时间点不一致时，无法用同一个切片安全裁剪时间戳和数据。

### 判定标准

| 状态 | 完整条件 |
| --- | --- |
| **通过 `pass`** | 每个流至少有一个数据字段；各字段不是 object 或标量，且第一维长度与 timestamps 相同。 |
| **告警 `warn`** | 不会出现；本规则不使用 warn 状态。 |
| **失败 `error`** | 缺数据字段、无样本维、object dtype 或与 timestamps 长度不一致为 error |

**边界怎么算：**

- 结构校验按离散条件判定，不进行隐式修复或默认跳过。

### 具体检查项

1. 除 timestamps 外必须至少存在一个数据字段。
2. 检查每个非 timestamps 数据字段至少具有一个样本维。
3. 拒绝 object dtype，因为其中元素的结构和长度无法按统一数组契约验证。
4. 每个数据字段的第一维必须与 `len(timestamps)` 完全相等。
5. 标量、object 数组或长度不一致时按流和字段发布 error，不展开或截断数据。

## 失败后建议

1. 检查生产端字段名、dtype、shape 和样本维契约。
2. 修复上游序列化或转换逻辑后重跑，避免在质检端猜测结构。
